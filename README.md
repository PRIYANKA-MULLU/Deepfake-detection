# Deepfake Detection

## Final Year Project – AIML

This project is developed as a Final Year Graduation Project by **Lalitha Priyanka Mullu** from the **Artificial Intelligence and Machine Learning (AIML)** branch.

## Project Overview

Deepfake Detection is an AI-based system designed to identify manipulated or fake videos/images created using deep learning techniques. The project helps in detecting fake media content and improves digital media security.

The system uses Machine Learning and Deep Learning techniques to analyze facial expressions, frame inconsistencies, and image patterns to determine whether the media is real or fake.

---

## Features

- Deepfake video detection
- Real vs Fake classification
- User-friendly web interface
- AI-powered prediction system
- Video upload and analysis
- Fast detection process
